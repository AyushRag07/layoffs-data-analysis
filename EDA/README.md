# 🌍 SQL Exploratory Data Analysis – Global Layoffs Dataset

## 📌 Project Overview

This project delivers a structured **Exploratory Data Analysis (EDA)** of global layoff data using SQL, with the goal of identifying **macro trends, company-level impact, and industry patterns**.

The analysis transforms raw layoff records into actionable insights that can support **business strategy, workforce planning, and market analysis**.


## 📂 Dataset

- **Source:** Kaggle – World Layoffs Dataset  
- **Data State:** Pre-cleaned dataset from prior data cleaning pipeline  
- **Scope:** Multi-year global layoff data across companies, industries, and geographies  



## 🛠 Tech Stack

- **SQL (MySQL):** Data querying, aggregation, and trend analysis  
- **GitHub:** Version control and project documentation  



## 🔍 Analytical Scope

The analysis focuses on identifying high-impact layoffs and uncovering patterns across multiple dimensions:

### Company-Level Analysis
- Largest single-day layoffs  
- Companies with highest cumulative layoffs  
- Identification of companies with **100% workforce reduction**  

### Geographic Analysis
- Layoffs by location and country  
- Regional concentration of workforce reductions  

### Industry & Stage Analysis
- Industry-wise layoff distribution  
- Impact across different company growth stages  

### Time-Series Analysis
- Year-over-year layoff trends 



## 📊 Key Insights

- A subset of companies executed **complete workforce terminations**, indicating shutdowns or severe financial distress  
- Layoffs were **clustered within specific industries and regions**, highlighting sector-specific downturns  
- A small number of companies contributed disproportionately to overall layoffs, indicating **high-impact events**  
- Layoff activity shows strong correlation with **economic cycles and market conditions**  
- Rolling monthly trends reveal **clear periods of escalation**, useful for identifying early warning signals  


# 🚀 Business Impact

This analysis enables:

- Identification of **high-risk industries and regions**  
- Understanding of **macro workforce reduction trends**  
- Early detection of **economic stress signals**  
- Data foundation for **dashboarding and predictive modeling**
